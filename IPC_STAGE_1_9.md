# Stage 1.9 — TileLang Windows NVCC host-compiler fix\n\nThe standalone NVCC probe already proved that MSVC 14.39 + CUDA 12.9 + sm_86 works.\nThe TileLang command contained two `-ccbin` flags; the second came from `compile_flags` and\nwas mangled from a Windows path such as `D:\\Setup\\...` into `D:Setup...`, causing NVCC to\nreport `A single input file is required`.\n\nStage 1.9 removes the absolute-path `compile_flags` override. The Windows bootstrap still\nsets `NVCC_CCBIN=cl.exe`, `CC=cl.exe`, `CXX=cl.exe`, and puts the selected MSVC `bin\\Hostx64\\x64`\ndirectory first in `PATH`. This yields a single, valid `-ccbin=cl.exe`.\n\nDo not patch installed TileLang.\n
